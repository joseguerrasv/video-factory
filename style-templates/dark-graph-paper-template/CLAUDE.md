# Template instructions

Follow the root CLAUDE.md and this template's DESIGN.md. Copy this template
into a video project before editing; there the project's `frame.md` (the active
brand) overrides this template's palette and typography. Read the root
style-templates/README.md for required assets. Use the HyperFrames skills
(`hyperframes` entry point, then `hyperframes-core` and `hyperframes-animation`). Lint, preview, and inspect rendered frames after
modifying a composition. All publishing requires the user's authorization.
